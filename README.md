# 장기 보유형 주식 매수/매도 타이밍 분석기

한국(KOSPI/KOSDAQ)과 미국(NYSE/NASDAQ) 주식을 대상으로, **최소 6개월 이상 보유**를 전제로 매수/매도 시점을 기술적 지표 기반으로 판정하고 근거를 함께 보여주는 도구입니다.

- 일봉·주봉 기반 장기 추세 국면 + 상대강도 로직. RSI 30/70 단타 룰이 아닙니다.
- 온디맨드 실행 — 매일 도는 감시봇이 아니라, 거래하고 싶을 때만 돌립니다.
- 매도 신호는 의도적으로 둔감하게 설계했습니다: 종목별 손절 임계치(%) 아래로 떨어지기 전까지는 청산 판정 자체를 내지 않습니다.

## 실행 방법

### GitHub Actions (설치 없이)

저장소의 **Actions → 종목 분석 → Run workflow**에서 `tickers`에 쉼표로 구분한 티커를 입력하고 실행하세요(비워두면 `positions.yaml` + `watchlist.yaml` 전체를 분석합니다). 결과는 실행 페이지 Job Summary에 표로 출력됩니다. 시크릿 설정이 필요 없습니다.

매수 또는 청산 신호가 발생한 실행에서만 "매매 신호 로그" 이슈에 코멘트가 남습니다. 신호가 없으면 아무것도 만들지 않습니다.

### 로컬 CLI

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

python -m stockta analyze AAPL 005930     # 지정 종목
python -m stockta analyze                 # positions.yaml + watchlist.yaml 전체
python -m stockta analyze --html out.html # HTML 리포트 추가 출력
```

## 종목 등록

**`positions.yaml`** — 보유 중인 종목 (청산 판정 대상):

```yaml
positions:
  - ticker: "005930"
    avg_price: 72000
    buy_date: "2026-01-15"
    stop_loss_pct: -10      # 이 수익률 이하로 떨어지면 청산 판정 시작
    trailing_pct: -15       # 선택: 매수 후 최고가 대비 하락률 임계
```

**`watchlist.yaml`** — 미보유 관심 종목 (매수 판정 대상):

```yaml
watchlist: ["NVDA", "000660", "MSFT"]
defaults:
  stop_loss_pct: -10
```

CLI/Actions에 티커를 직접 넘기면 그 티커만 분석합니다. 직접 넘긴 티커가 `positions.yaml`에도 있으면 매수 스코어와 청산 판정을 함께 보여줍니다.

## 판정 로직 요약

1. **게이트** (점수 이전에 선행 판정): 시장 국면(지수 > SMA200), 종목 장기 국면(Close > SMA200), 추세 유효성(ADX ≥ 20), 실적 임박 여부.
2. **매수 스코어** (게이트 통과 시 0~100): 추세 견고성(20%) · 상대강도(25%) · 진입 위치(20%) · 모멘텀(15%) · 수급(20%). 70점 이상 적극 매수, 55점 이상 분할 매수, 40점 이상 관망, 그 아래는 진입 부적합.
3. **청산 판정**: 평소엔 신호 없음(HOLD). 수익률이 종목별 임계치 아래로 떨어지면 그때부터 200일선 상태로 전량/부분 청산을 판정. 트레일링 스탑은 게이트와 무관하게 독립 작동.
4. **분할매수 플랜**: 1~3차 진입가와 손절선을 ATR·이동평균 기준으로 산출.

모든 임계값·가중치는 [`stockta/config.py`](stockta/config.py) 상수로 모아 조정 가능합니다.

## 명시할 한계

- 기술적 분석은 확률적 도구이며 수익을 보장하지 않습니다. 신호는 참고용입니다.
- **시장 국면 필터의 트레이드오프**: 하락장 회피로 드로다운은 줄지만, 강세장에서는 buy-and-hold 대비 언더퍼폼할 수 있습니다.
- **상대강도(RS)는 유니버스 백분위가 아닙니다**: 전 종목 스캔이 없으므로 IBD식 1~99 등급이 아니라 지수 대비 상대 성과로 근사한 값입니다.
- 지표는 후행성을 가지며, 급변 구간(어닝 서프라이즈, 정책 이슈)에서 신뢰도가 급락합니다.
- 6개월 보유 전제이므로 진입 신호가 자주 뜨지 않는 것이 정상입니다.
- 배당·액면분할은 `auto_adjust` 처리에 의존하며, 한국 종목의 유상증자 등 일부 이벤트는 반영이 불완전할 수 있습니다.
- 가중치·임계값은 이론적 근거로 정한 초기값이며 백테스트로 검증되지 않았습니다.
- 한국 종목의 외국인·기관 순매수 데이터(pykrx)는 네트워크 환경에 따라 조회가 실패할 수 있으며, 실패 시 해당 규칙만 `N/A` 처리되고 나머지 분석은 정상 진행됩니다.

### 의도적으로 넣지 않은 지표

- **피보나치 되돌림**: 앵커(고점/저점) 선택이 주관적이라 자동화 시 재현성이 낮습니다.
- **일목균형표 / Supertrend**: 이미 있는 추세 지표와 같은 질문에 답합니다(중복).
- **스토캐스틱**: 주봉 RSI와 같은 질문에 답합니다(중복).

```bash
pip install pytest
pytest -q
```

합성 데이터(`tests/synth.py`)로 지표·게이트·스코어링·청산 로직을 검증합니다. 실시세 조회는 네트워크가 열린 환경(로컬 또는 Actions)에서만 가능합니다.
