# 밀담 릴레이 (맥에서 실행)

두 폰이 주고받는 **암호문만** 중계·보관하는 최소 Nostr 릴레이입니다.

## 이 서버가 하지 않는 것 — 불변식 #1

**앱 코드(HTML/JS)는 이 서버가 절대 서빙하지 않습니다.**

이건 편의상의 선택이 아니라 이 설계 전체를 떠받치는 조건입니다.

| 침해 대상 | 공격자가 얻는 것 | 결과 |
|---|---|---|
| 이 릴레이 | 암호문 + 메타데이터(누가·언제·몇 건) | 평문·키는 못 얻고 위조도 불가. 피해가 한정됨 |
| 앱 코드를 서빙하는 곳 | 악성 JS 주입 → **개인키·평문 유출** | E2EE가 통째로 무의미. **복구 불가** |

그래서 맥이 통째로 털려도 대화 내용은 안전합니다 — 단, **맥이 코드를 서빙하지
않을 때만** 그렇습니다. 앱은 Codeberg Pages / Cloudflare Pages / GitLab Pages /
Netlify 같은 별도의 정적 호스팅에 두세요.

## 설치

```bash
cd relay
npm install
cp config.example.json config.json
```

`config.json`의 `allowedPubkeys`에 **폰 A, 폰 B, 도우미**의 공개키(64자 hex)를
넣습니다. 각 폰의 공개키는 앱의 친구 추가 화면에 뜨는 초대코드에서 확인할 수
있고, 도우미의 것은 도우미를 처음 실행할 때 출력됩니다.

```json
{
  "port": 18787,
  "bindHost": "127.0.0.1",
  "allowedPubkeys": ["<폰A pk>", "<폰B pk>", "<도우미 pk>"],
  "retentionDays": 7,
  "maxEventBytes": 131072
}
```

`bindHost`는 `127.0.0.1`로 두세요. 외부 노출은 아래 Tailscale이 담당합니다.

## 실행

```bash
npm start        # 또는 node relay.mjs
```

## Tailscale 종단 (S8-c)

폰에서 이 릴레이에 닿으려면 **유효한 인증서를 가진 wss://** 가 필요합니다.
브라우저는 자체서명 인증서로 열리는 WebSocket을 거부하므로, Tailscale이
발급해주는 인증서를 씁니다.

**충족해야 하는 결과**

1. 맥·폰 A·폰 B가 **같은 tailnet**에 있을 것
2. `https://<맥>.ts.net/relay` → `http://127.0.0.1:18787` 로 프록시될 것
3. 브라우저에서 `wss://<맥>.ts.net/relay` 접속이 **유효한 인증서로** 성립할 것
4. 공유기에서 릴레이 포트를 **포트포워딩하지 않을 것** — 모든 접근은 tailnet 안에서만

**명령 예시** (정확한 형태는 설치된 버전의 `tailscale serve --help`를 따르세요)

```bash
tailscale serve --bg --https=443 --set-path=/relay http://127.0.0.1:18787
tailscale serve status      # 위 3번이 성립하는지 확인
```

그다음 앱 쪽 종단을 맞춥니다. **반드시 이 스크립트로** 바꾸세요 —
`js/config.js`와 `index.html`의 CSP가 어긋나면 앱이 아무 오류 없이 조용히
오프라인이 됩니다.

```bash
node tools/set-relay.mjs wss://<맥>.ts.net/relay
```

## 접근 통제 (S8-d)

네트워크 도달 가능성과 애플리케이션 접근 통제는 **별개의 방어선**입니다.
Tailscale이 남을 막아준다는 이유로 릴레이를 무방비로 두지 않습니다.

- **쓰기(EVENT)**: 인증 불필요. 서명 검증이 이미 완전히 막습니다. 여기에 더해
  kind 1059만, 크기 상한 이내로, 수신자(`p` 태그)가 `allowedPubkeys`에 있을
  때만, 보관 기간과 시계 오차를 감안한 시각 창 안에 있을 때만 저장합니다.
- **읽기(REQ)**: **NIP-42 인증 필수.** 연결 즉시 챌린지를 보내고, 서명된
  kind 22242 이벤트로 인증하기 전에는 어떤 이벤트도 주지 않습니다. 인증 키가
  `allowedPubkeys`에 없으면 계속 거부됩니다.
  이게 없으면 tailnet에 닿는 아무 기기나 `#p` 필터 하나로 두 사람의 전체
  암호문·타이밍·발신량을 열람할 수 있습니다.
- `#p` 없는 REQ는 이벤트를 하나도 반환하지 않습니다(전체 덤프 방지).
- 한 연결에서 초당 EVENT 20건을 넘으면 연결을 끊습니다.

## 로그 정책

공개키와 이벤트 id는 **앞 8자만** 남기고, `event.content`는 **어떤 경우에도**
로그에 남기지 않습니다. 탈취된 맥에서 로그가 메타데이터 수집처가 되지 않도록
하기 위함입니다.

## 저장

- `state/events.jsonl` (권한 `0700` 디렉터리)에 append
- 시작 시 `retentionDays`가 지난 항목은 제외하고 로드
- 1시간마다 만료분을 정리하고 파일을 재작성
